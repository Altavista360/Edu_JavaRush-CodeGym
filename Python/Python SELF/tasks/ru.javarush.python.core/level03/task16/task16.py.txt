Всего на шахматной доске 64 клетки. Используйте цикл for и функцию range() для итерации по клеткам и функцию print() для вывода результата. ### JavaRush
## Требования:
# • Программа должна использовать цикл for для итерации по клеткам шахматной доски.
# • Программа должна использовать функцию range() для определения диапазона итерации от 0 до 63 включительно.
# • Количество зерен на каждой клетке должно быть рассчитано как 2 в степени индекса клетки.
# • Программа должна использовать функцию print() для вывода номера клетки и соответствующего количества зерен.
# • Результат должен быть выведен в формате "Клетка X: Y зерна", где X — номер клетки (начиная с 1), а Y — количество зерен.
